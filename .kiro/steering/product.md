# Product Overview

ホルター心電図解析支援アプリ（クライアントアプリ）のライセンスと、推論の利用回数を管理するサーバー。クライアントアプリはライセンスキーで有効性を確かめ、推論のたびに利用を記録する。運営者はライセンスを発行・停止し、利用状況を確認する。

## Core Capabilities

- **有効性判定**: ライセンスキーが登録済みで有効（停止中でない）かを返す。
- **利用回数の制限**: 推論の利用を記録し、日本時間の暦月ごとの月間上限回数を超える記録を拒否する。同時要求でも上限を超えない。月間上限 0 は上限なし。
- **運営者の管理**: 管理 API（Bearer トークン）と管理画面（`/console`、Cloudflare Access で保護）で、発行・停止・再開・利用履歴の参照を行う。
- **操作の追跡**: 管理画面での変更はすべて操作記録に残し、利用履歴はクライアントから変更・削除できない。

## Target Use Cases

- クライアントアプリが起動時や推論前にライセンスを確認し、推論ごとに利用を記録する。
- 運営者が顧客（ライセンシー）ごとにライセンスを発行し、契約終了や不正利用時に停止する。
- 運営者が月ごとの利用回数を確認し、請求や契約見直しに使う。

## Value Proposition

- 利用回数の判定をサーバー側の時刻と件数で行うため、クライアント側の改ざんで上限を回避できない。
- ライセンスキーは秘密情報として扱い、URL・ログ・画面の遷移先に出さない。
- Cloudflare Workers と D1 の上で動き、サーバーの運用がほぼ不要。

## Boundaries

- 推論の入力データや結果は受け取らず、保存もしない（記録するのは利用日時だけ）。
- 課金・決済、IdP での本人確認は扱わない（本人確認は Cloudflare Access と IdP に委ねる）。
